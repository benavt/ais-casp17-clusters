# CASP17 AIS cluster atlas

Saved structural analyses of five CASP17 targets, with 11,000 original models per target from eleven AIS methods. Open the GitHub Pages site to inspect PCA, UMAP and t-SNE projections and a structural medoid from every cluster. Each target has its own frozen model membership and provenance record.

Coordinates, scores and population counts are predictions and sampled ensemble summaries, not experimental validation or equilibrium probabilities. BioEMU and BioEMU2 have no assigned confidence scores.

Browser libraries: Plotly.js (MIT) and 3Dmol.js (BSD; license retained under assets). Scientific processing uses the pinned [Structure Clustering workflow](https://github.com/benavt/Structure_Clustering).
